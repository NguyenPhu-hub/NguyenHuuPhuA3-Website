- config.php, cac ham helper (e, base_url, csrf_field, verify_csrf, flash...);
- CSDL va cac bang categories, products, product_images;
- cau hinh upload va cac hang so UPLOAD_*.

Cach lam:
1. Giai nen ZIP.
2. Mo thu muc bang Visual Studio Code.
3. Neu da co project Buoi 1 + Buoi 2: copy cac thu muc app/ va public/ trong goi nay
   vao project nen, sau do doi chieu tung file voi PDF goc.
4. Neu chua co Buoi 1 + Buoi 2: can bo sung project nen truoc; khong nen chay rieng
   cac file placeholder trong goi nay.
5. Bat Apache/MySQL va extension PHP gd, fileinfo theo yeu cau cua tai lieu.

kiem tra lai truoc khi chay.
